# Aditya Agrawal - Personal Website

Interactive museum-style personal website for Aditya Agrawal, a quantitative researcher and developer working across financial markets, mathematics, systematic trading, and software.

Live site: https://adityaag.com

## Stack

- Next.js and React
- TypeScript
- Three.js and WebGL
- Framer Motion
- CSS

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run build
```
